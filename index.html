Method.

MATE combines diffusion policies across modalities, representations, and inference rates, reusing slower predictions while incorporating fresh guidance from faster policies.

Modular

Combine independently trained policies without joint retraining.

Rate-preserving

Keep fast feedback responsive alongside slower policies.

Asynchronous Multi-Rate Composition.

Policies share a compatible action space and diffusion parameterization; their query times, horizons, and reference frames may differ.

  1. Selectthe overlapping prediction horizon.
  2. Rebasethe noisy sample and cached guidance into Policy 2’s frame for denoising.
  3. Fusealigned guidance with normalized, nonnegative weights.
  4. Map backto the original frame, replace the overlap, and run the DDIM update.

Composing multiple policies

For multiple policies, apply the same selection and rebasing to every available component before combining guidance.

Reference-frame Rebase.

Predictions made at different times use different reference frames; MATE aligns them to the robot’s current frame before combining them.

Rebase formulas & derivation Actions, noisy samples, and predicted noise
01

Relative action

Full affine transform

a′=A2←1a+b2←1
02

Noisy sample

Offset scaled by the diffusion schedule

a′k=A2←1ak+α¯kb2←1
03

Predicted noise

Orthogonal linear transform only

ε′k=A2←1εk

Key property. The orthogonal linear transform preserves standard Gaussian noise.

We derive a common-frame representation for clean actions, noisy samples, and predicted noise.

01

Transform between query frames

The robot poses at the two query times define a relative rotation and translation:

T2←1=T2−1T1=(R2←1,p2←1)

Choose action coordinates that make this rebase affine with an orthogonal linear part.

02

Write the 10D action rebase as an affine map

Why column-wise 6D matters

A frame rotation acts independently on each rotation-matrix column. Stacking the first two columns gives a linear 6D rotation rebase:

R′=R2←1R⇒ri′=R2←1ri R6d′=blockdiag(R2←1,R2←1)R6d

This derivation requires an orthogonal linear rotation rebase, provided by column-wise 6D coordinates. Euler angles and axis-angle coordinates do not follow the same rule.

Each action contains 3D translation, 6D rotation, and a gripper command:

a=[xT,R6dT,g]T∈ℝ10
A2←1=blockdiag(R2←1,R2←1,R2←1,1) b2←1=[p2←1T,03T,03T,0]T
a′=A2←1a+b2←1

The block-diagonal rotation matrix A2←1 is orthogonal.

03

Rebase the clean-action estimate

At diffusion step k, estimate the clean action from the noisy sample and predicted noise:

a^0=1α¯kak−1−α¯kα¯kεk

Apply the affine transform and regroup:

a^0′=A2←1a^0+b2←1=1α¯k(A2←1ak+α¯kb2←1)−1−α¯kα¯kA2←1εk
04

Read off the rebase rules

Matching the estimator in frame T2 gives:

a′k=A2←1ak+α¯kb2←1 ε′k=A2←1εk

Translation enters the noisy sample scaled by √ᾱk, but not the noise. Since A2←1A2←1T = I, noise covariance is preserved.
